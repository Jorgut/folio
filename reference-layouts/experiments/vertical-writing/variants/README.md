# Vertical layout variants

Independent A4 layout study: seven Chinese and seven traditional Mongolian pages.

Each language includes a cover, a pure-text reading page, four image/body templates, and a closing page. This is a template demonstration sequence, not a continuous authored article.

Reusable body templates: text only, wide image, side image, paired images, and inset segmented flow. Cover and closing structures can be reused, but their title, image balance and content density should be adapted for each publication. Covers here are title-led opening designs, not press-ready cover wraps with spine/back cover.

- Wide image with body below.
- Side image with full-height body.
- Paired images with body below.
- Inset image with separate text regions; not automatic text wrapping.

The page canvas is fixed at 794 x 1123 CSS pixels and scaled proportionally for previews. Chinese columns progress right to left; Mongolian columns progress left to right. Photographs remain upright.

Titles occupy a dedicated vertical rail: rightmost for Chinese, leftmost for Mongolian. Image and body regions sit alongside the title rather than below a horizontal heading band. Running heads, image captions and folios remain horizontal.

Text is repeated layout-test material, not editorial copy. Mongolian wording, shaping, and line breaks require review by a competent reader. No native InDesign/Figma export or print-production acceptance is claimed.

Open index.html or wireframe.html directly. The Guides control marks the content boundary. Mongolian font licensing is in ../fonts/OFL.txt. Traditional Chinese body paragraphs consistently use a two-character first-line indent; titles, captions and endnotes do not.
