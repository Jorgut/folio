## 第一条视觉记录

Architecture Portfolio 的封面预览使用大幅橙色底、黑色压缩字形和明显的上下分区。首批缩略图同时出现：四项配图目录、四项纯文字目录、章节引入页。观察仅限这些可见页。

可提炼的研究问题：同一章节是否同时需要图像式和文字式导航？章节页如何与项目详情页形成密度变化？不将该模板的颜色、字号或布局坐标直接视作 Folio 默认规则。

## 六种原创图片布局：待样板验证

| ID | 布局 | 对齐关系 | 图像处理与限制 |
| --- | --- | --- | --- |
| L01 | 主图＋说明栏 | 图片与说明栏顶边共线；正文左边固定 | 主图优先完整呈现空间，过度裁切时改用另一结构 |
| L02 | 双图比较 | 图框同高；图注起点与各自图框左边一致 | 主体尺度尽可能可比；不同原图比例允许留白，不拉伸 |
| L03 | 主图＋两张细节图 | 细节组合与主图共用上下边界 | 图注空间计入组合总高度；细节图不得冒充全景 |
| L04 | 横图＋竖图 | 顶边一致；按原图比例计算宽度 | 不强制两图同宽；无法兼顾高度与裁切时换布局 |
| L05 | 多图序列 | 共用基线、统一间距与编号位置 | 按动线或观察顺序，限制到可辨识的图片数量 |
| L06 | 图片＋分析结论 | 图片与结论具有明确阅读关系 | 结论必须指向图中可见证据；图注和结论分工明确 |

六类是图片布局，不是完整演示文稿 taxonomy。章节、纯文字、图表、表格、时间线、流程和商业画布另行归类。

## 样板的初始参数

这是原创测试参数，不是 Pitch 测量结果，也不是现有 Folio 的强制规范。

- 16:9，参考画布 1280×720。
- 内容外边距 48，栏间距 24；内容跨度允许 6:6、8:4、9:3，按文字量和图片比例选择。
- 标题、内容、图注、页脚分别有锚点，不要求所有页面占满同样高度。
- 现场演示与阅读资料使用不同文字容量与字号配置。
- 图片无拉伸；裁切焦点显式记录。空间整体、主体、招牌等关键证据不得意外裁掉。
- 辅助线作为可关闭的审阅层；干净导出不包含辅助线。
