# 45 页逐项 QA 与适用性评估

日期：2026-10-11。对象：wireframes.html 当前 v0.4。结论：完成全部页面的代码与内容角色审查，不是全部页面的渲染验收。此次仅更新报告，未调整布局。

## 需要调整

修复更新：L38 的“竖图 A”已改为“辅助图 A”，不再暗示槽位比例；L43 的纵轴说明已改为“易用程度：由下至上增高”。新增四项回归断言通过。下方发现及逐页表保留为审查时记录，这两项现已完成代码修复，渲染验收仍待完成。

**P2 / L38：竖图标注与槽位几何不一致。** 四列两行等高网格中，第二图只占一列一行。根据 16:9 画布、内容边距、标题/页脚/间距和图注约束，该单列图框宽约 21.6cqw，高约 15cqw，为横向槽位，却标为“竖图 A”。它可以容纳竖向原图，但那需要另设 contain 与留白规则，当前只有铺框的线框占位。应改为中性的图像标签，或明确显示竖向容纳区域；不应把素材比例与图框比例混为一谈。此为代码几何推导，非截图测量。

**P2 / L43：纵轴方向标识有歧义。** 易用程度是纵向维度，轴标签却用“低 → 高”的横向箭头。应在纵轴上下分别标高/低，或明确为“由下至上”，不能让方向依赖旁边说明。点的位置与标签是否遮挡仍待截图检查。
