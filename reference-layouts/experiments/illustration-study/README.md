# Illustration / Editorial Portfolio Supplement

Two new structures (L46, L47) and three variants (L09-A, L01-A, L09-B), arranged as a five-page study. IDs are provisional until merged into the main catalogue. Existing L01-L45 are unchanged.

- Neutral dashed bounds indicate placement for transparent-background images; no subject silhouette or actual illustration is prescribed.
- Sideways English headings rotate the whole line; they are not vertical-script typesetting.
- Chapter crops may touch the canvas edge. Text stays within page margins.
- Paired annotations describe the same central subject without implying a flowchart.
- Warm-gray hatching matches the portfolio preview palette. No reference artwork is reused.

HTML uses fixed-ratio SVG pages: responsive display scales the whole page instead of reflowing its internal layout. Open index.html; select a page to inspect its SVG.

Source: build.mjs; rebuild with `node build.mjs`. Published deliverables: index.html, five SVG pages, [editable native wireframe PPTX](deliverables/folio-illustration-study-en-v3.pptx) and [native wireframe PDF](deliverables/folio-illustration-study-en-v2.pdf). Source SVGs and native files were individually rendered and reviewed; see QA.md. Browser gallery and target-editor acceptance remain pending. This supplement does not change the published 45-page count.

The separate [real-image gallery](real-image-test/index.html) tests three sourced images across five pages. Its latest chapter frames use full-height 4:5 and 6:5 proportions, with no page-wide footer across the images. The right detail crop removes the scan's side borders. See [licenses](real-image-test/sources.html) and [test notes](real-image-test/README.md). These are rendered page images, not the native wireframe files above. Original downloads, previous candidates and build records are retained locally, excluded from this public release.
