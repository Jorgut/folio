## Maintenance Rules

- If the Pinterest board gains new pins, append new rows rather than rewriting history.
- If a pin duplicates an existing structure, mark it as a duplicate/variant and do not add a new template.
- Add a new template family only when at least two references show a distinct reusable structure, or one reference solves a recurring Folio layout problem.
- Do not commit downloaded thumbnails or source images. Use screenshots only for private review unless the image is yours or explicitly licensed.
